Modern Cryptography

From breaking classical ciphers by hand to benchmarking modern and post-quantum primitives in Python's pyca/cryptography.

Cryptanalysis

Breaking the Vigenère Cipher

Built
Wrote tooling to find repeated ciphertext substrings, infer key length from their spacing, and split the text into Caesar-shifted columns to recover the key.
Takeaway
Polyalphabetic ≠ secure: structure leaks through repetition, and classical ciphers fall to frequency analysis once the period is known.
Snippet
# Kasiski: repeated substrings reveal the key period
for length in range(min(12, len(text)), 2, -1):
    counts = find_repetitions(text, length)
    if counts:
        print(length, counts)
Tools
PythonKasiski examination
Symmetric crypto

Block & Stream Ciphers — DES, AES, ChaCha20

Built
Implemented encrypt/decrypt round-trips for DES, AES, AES-CTR, RC4 and ChaCha20, observing mode-of-operation and IV handling first-hand.
Takeaway
The cipher is rarely the weak point — mode of operation, IV uniqueness and an integrity check decide whether the construction is actually safe.
Tools
Pythonpyca/cryptography

Key Exchange & the One-Time Pad

Built
Built Diffie-Hellman key agreement and a one-time-pad XOR demonstrator to show perfect secrecy and its impractical key-management cost.

Perfect secrecy is real but unusable at scale — which is exactly why real systems spend asymmetric maths once, then switch to symmetric.

Penetration Testing

Structured web-application security testing against a deliberately vulnerable PHP lab — every finding paired with its secure-coding fix.

Web app security · defensive

Cross-Site Scripting — 10 Findings, 10 Fixes

Built
Catalogued ten distinct XSS variants (reflected, DOM-based, attribute- and comment-context, filter bypasses) in a lab app and documented the correct mitigation for each.
Takeaway
Denylists and custom sanitisers lose; contextual output encoding wins. Every finding resolved to htmlspecialchars with ENT_QUOTES, json_encode for JS context, or safe DOM sinks.
Snippet
// Context-correct output encoding beats every blacklist
echo htmlspecialchars($input, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
Tools
OWASP ZAPXAMPPPHP
